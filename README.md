# Smart City Traffic System

A core traffic management system implemented using Java RMI and RPC.

## Project Structure

* **`src/`**: Contains the core source code for the traffic management application.
* **`SmartCityTrafficSystem.iml`**: IntelliJ IDEA module file for the project.
* **`accidents.log`**: Log file for recording accident-related events and data.
* **`.gitignore`**: Specifies untracked files and directories to ignore in version control.

## Features

* Core traffic management functionality built using RMI and RPC.
* order more priority accidents  for first.
